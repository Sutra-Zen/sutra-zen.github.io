# 十四本共用圖框與文字避讓

日期：2026-11-23。分支 `fix/reader-stable-artwork`，由已發布 PR77 merge `3a72b2e33a086714ce30cd80fbebb3ab641d0dc3` 建立；起始工作樹乾淨，repository 與 origin 已核對。

## 作者要求與結果

遊戲複習的「回收集書架」縮為「回到書架」。返回、目錄、原經／回地圖及本頁經文按鍵的實際範圍會參與文字留白計算，包含遊戲橋接完成後變寬的標籤，以及安全區造成的垂直位移。

十四本的公開讀本與遊戲模式共用 `reader-layout.js` 和 `reader-controls.css`。橫式的上方口白與下方原經各預留兩行及控制項空間，不再隨當頁字數改變插圖高度。長口白與完整原經可在各自文字區捲動，並保留「本頁經文」入口。直式維持文件上下捲動，口白至少留兩行、較長段落自然展開，插圖本身依共同高度置中，不壓掉文字。

圖片保留自然比例：同一視窗下，較窄圖片只減少寬度，與較寬圖片等高。`#art-frame`、六處的巢狀 `#art-layer` 與實際插圖同框，原有百分比標註、cqw 字級、局部遮罩及聚焦資料仍以完整畫面為基準。

作者追加的心經頁沿用前幕圖框比例與共同高度，上方口白與一般插圖頁對齊。原心經直書、由右向左捲動、標題、紅色重點與隱藏的口白高度量測節點均保留。直接續讀心經時，以書本的預設比例恢復，不要求先翻回圖片；五陰、六處使用 `data-art-ratio="1.5"` 作為預設。

文字結語、後記與文字總結改為從相同的頂端開始，保留自己的標題、完整段落、引文與表格，整個內容區可捲動，不套兩行裁切。一般插畫總結仍使用插圖框及原疊字；窄橫式額外總結文字放在同位置的獨立可捲動總結帶，保留原口白的隱藏狀態，避免總結跟著隱藏或把插圖再縮小。直式保留原圖下方的完整補充文字。五陰的長篇總結在窄直式移到固定圖框之後，讓文字自然撐高文件，原經入口不會被溢出的段落壓住；寬直式與橫式恢復原圖內可捲動總結。

開場下方「點一下進入選單」恢復純白字、無底色或邊框的外觀，保留觸控與鍵盤操作及選取文字不跳過、防穿透、減少動態與自然播完。開始／繼續旅程採與設定相同的深色底、淺青字，保留中心標題與既有貓咪背景。

## 尺寸與例外

共用普通圖框參考比例是 `1.8`，略大於現有普通插圖的最大比例 `1681 / 935`。橫式高度取文字帶之外的可用高度與「畫面寬度扣除翻頁軌道」能容納的高度之較小值；直式依內容寬度除以 `1.8`。這是版面尺寸，不修改原圖像素。

實際素材以約 16:9 與 3:2 為主；沒有把作者所稱的少數圖片逕記為已驗證 4:3。自然比例 4:3 也使用同一 fitting 計算。詳 [原圖中繼資料稽核](ratios-audit.json)。

四聖諦的 `related.jpg` 是 `1536×458` 的超寬影片卡資料圖；其共用畫布仍與前後頁等高，圖片以 contain 完整呈現，因此實際畫出的資料條上下會有留白。資料條沒有需要以圖像百分比定位的新增標註；沒有裁掉或拉伸原圖。心經可延續同一畫布，不會忽然縮成另一張卡片。

## 實作與保存界線

- `reader-layout.js` 只處理版面與文字區捲動，不取代任何 `showPage()`、分段、經文、頁數或圖片渲染。
- 新屬性 `--reader-*` 與 `.reader-stable-artwork`／`.reader-framed-heart`／`.reader-framed-ending` 不與各書既有 `--caption-space`、`--scripture-space`、`--image-space-height` 的 observer 寫入互相覆蓋。
- 從正常前幕進入心經會記住該次圖框比例；這是記憶體版面狀態，沒有新增本機存檔或語言相關 ID。
- 圖下的既有 `#outside-labels` 完整節點放入口白，額外總結文字只在需要的橫式情境使用同位置的獨立總結帶；切換成文字後記時恢復原內容容器，沒有複製或另維護原稿。
- `play/collection/catalog.js` 只改一個介面標籤；bridge 對純資料使用新版 URL，collection／route／story／city store 的模組單例與格式不改。

十四本 HTML 只更新共用資源快取、加入共用 layout script，五陰／六處補充版面比例 metadata；原正文、口白、原經、圖片與聚焦資料不改。九本原本沒有共用 layout 的讀本新增同一支 script。書本原生 HTML／CSS／JS 是目前閱讀器來源，各內容 builder 只產資料與導讀；七覺支離線打包器補入 `reader-layout.js`，並重建現成下載 ZIP 與 manifest（30 個檔案）；原插圖與內容資料仍逐位元保留。

UI／回程快取版本 `stable-art-1`，遊戲入口仍由 `scripts/build-game-entry.py` 產生，原站首頁、心智圖、十四本公開入口、十五頁 SEO、sitemap、robots、Google 驗證檔與 Pages `main:/` 保持。QA 排除目錄累計二十四處。
