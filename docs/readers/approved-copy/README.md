## 口白版面與全十四本檢查

作者附件為五陰44頁：原稿含兩個硬換行，橫式顯示為三行；原共享字幕帶只預留兩行。修改前實測1916×963與1024×768：p高84px、帶高72px，原生捲動能看到末行，但初看被截。844×390也有同樣初始遮字。沒有把這個現象誤報成原稿字句遺失。

共享reader-layout現在為橫式統一預留**三行及段落間距**；預算由視窗與字級決定，不隨當頁行數變化。各本各頁仍共用同一圖高計算，插畫比例、圖內標註與聚焦遮罩保持。共享CSS僅讓橫式口白p依實際寬度自然換行，不再強制維持稿中的硬換行；原字串與語段不改。直式仍完整自然流動，保留原換行。超長口白／總結仍可捲讀全文，沒有縮字、裁字或另增閱讀步驟。

作者進一步要求檢查全部繪本，因此本輪另外逐本覆蓋全部1192個閱讀步驟及六種尺寸，檢查實際字形Range、初始前三行、父子裁切、完整可捲讀、圖片高度一致；不是只挑五陰44頁或只看能編譯。實際完成範圍、統計及截圖見[驗證紀錄](../../previews/approved-reader-copy/README.md)。
