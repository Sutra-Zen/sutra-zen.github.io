# 四聖諦尾聲先於城池／下一站

2026-11-23，從已發布 PR73 main `2720747323f4d3a05474bf0c2919ac5332810cb2` 建立 `fix/game-outro-before-next-station`。起始工作樹乾淨，origin 為 Sutra-Zen/sutra-zen.github.io。延續作者本輪遊戲修正與發布授權。

## 修正行為

原先五陰銜接只在「前往下一站」或開啟五陰時出現，先去城池安置法輪碼頭會把對話延後。本輪將正常首次完成順序改成：

**原四聖諦末頁明確完成 → 心得 → 疑退場 → 波旬 → 五陰湖短句 → 原完成／取得碼頭面板 → 城池安置或前往下一站。**

五陰短句在完成鏈內的按鈕為「看看旅程的變化」，先回取得面板，不會直接開五陰。安置完碼頭返回後，下一站不再插入同一段對話。前段明確略過仍先顯示五陰銜接；尾幕可明確略過並回閱讀回饋。完成鏈期間，一般底列導航、主讀本及地標不能提前分流，設定備份／重置仍可使用。

## 保存與歷史相容

`dialogue.show` 新增僅存在記憶體的 `context:'first-completion'`，傳給連續片段與 callback。原 scene ID、故事文字、正常 book-entry action 與閱讀資格不改，沒有新增閱讀完成／書籤或存檔 schema。

原 `doubt-recedes` 截止標記延後至五陰短句確認或明確略過後才寫。短句已顯示但尾聲未確認時，重整會優先恢復短句，不退回波旬、也不直接開書。舊版已確認波旬／退場但尚未看五陰短句、四聖諦仍在末頁、五陰又沒有任何書籤的玩家，回海圖會先補這個尾幕；一般沒有相關故事標記的歷史存檔不強插。已看短句、五陰已有書籤（包含 index0）或已讀者正常續讀／複習。四聖諦已回到非末頁複習時不強補；舊版曾繞行先看短句、卻還沒看波旬的存檔，仍先補未完的疑／波旬，不誤當整個尾聲已完成。

工具重看包含新順序的五陰銜接，但不寫故事／閱讀／城池，不發獎勵或自動讀書。原 receipt 與末頁驗證保留，`completed` 網址參數不構成完成或新過場憑證。城池是否安置不介入閱讀資格。

故事的 `seenSceneIds` 表示已顯示或已明確略過的呈現確認，不是實際觀看時長。明確略過前段時也確認波旬段，讓尾幕重整續看能與舊版繞行而未看波旬的存檔區分；不寫閱讀完成。從設定返回仍有對話時，鍵盤焦點回到對話的主要按鈕。
