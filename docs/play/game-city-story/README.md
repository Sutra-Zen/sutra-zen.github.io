## 開場與角色

`play/story/data.js` 將作者提供的開場故事、人物與UI文字集中管理，和原繪本口白、經典引文分開。只實作 `arrival-at-wheel` 一幕：

> 咦？我剛才明明還趴在窗邊等朋友回訊息……怎麼一抬頭，就到了法輪遺跡？進去看看！

對話框在海圖上方，人物肖像、文字與按鍵都是獨立元素。按「進去看看」經既有資格檢查進入四聖諦；「先看看地圖」關閉對話。已有閱讀位置或完成紀錄者不自動重播；所有玩家可在「工具 → 重看開場對話」觀看，此時按鍵回到目前合法關卡，不改主線。

新肖像依七覺支S11中央小貓及現有划船角色生成，沒有燈籠、皇冠或鬍子；來源、原生1254×1254尺寸與hash見 [素材紀錄](../../../play/story/assets/README.md)。它是待作者確認的暫用概念稿，不替換原繪本圖片。介面提供載圖失敗的文字操作，不因此阻止閱讀。

首次顯示時，獨立 `sutrazen.play.story.v1` 只保存版本與已顯示的scene IDs。localStorage不可用時試用獨立session紀錄，再退回本頁記憶體並提示；從不修改完成集合、書籤、舊站資料或解鎖資格。顯示過的開場可手動重看。進度備份仍為原有閱讀存檔格式；不依附對話紀錄。

actor/scene IDs 與語言無關，繁中完整可用，預留zh-Hans/en/ja，不顯示未完成語言選項。未來可新增五蓋或波旬的actor與scene，但本輪沒有自編後續台詞、反派圖稿或完整結局，也不把閱讀紀錄當作修證判定。

## 城池與來源

原色完整城圖保留，未解鎖部件改局部雲霧；海圖上的港口城池徽章移除，固定底列「城池」仍是入口。原圖範圍／全圖返回／半島避讓延續PR66，沒有重新擴外海。

依 [作者r3路線稿](../worldmap-v4/handoff/SutraZen_Codex_Route_Unlocks_v2.md) 分開呈現：

- SN35.245六門城喻：身體城池、四大廣場、六內處城門、念守門人、識城主、止觀使者、如實消息涅槃、八正道路。
- 教材與美術延伸：緣起輪、六念燈、精進花園、如意足船、四禪庭園、五根五力的既有區域連動、七覺支既有夥伴等。

《雜阿含》1175保留作平行對讀，不把四門／四識住混成巴利六門配置；五根五力、七覺支不標成這兩部城喻的明文。五根五力的教義連結另標《雜阿含》646等來源，場景光線與配置仍屬遊戲創作。七覺支使用現有繪本的念、擇法、精進、喜、輕安、定、捨角色，其中「定」是蓮花。城內念燈延續同一位念-守門人，其餘六位以S12原圖的SVG局部顯示，沒有另造一位念守門人。

這些原繪本局部仍含既有中文標籤，尚非正式獨立去背角色稿；未來切換介面語言不會自動完成原插畫翻譯。後續可補六位夥伴的正式獨立素材、各表情肖像及其餘劇情。新UI／對話／法義文字則由HTML或SVG文字呈現，沒有烙入新圖。

所有回饋沿用既有completed集合及 `deriveCityState()`，稀疏舊完成紀錄保持有效，缺來源書時不自動補完其他章節。新場景熱區內閱讀入口仍只能複習已完成的書；其他引導回目前關卡。十四本原公開閱讀器保持自由閱讀、原稿與操作不變。
