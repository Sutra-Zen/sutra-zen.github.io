## 本機試閱

從本專案根目錄執行：

```sh
git switch feat/picture-book-journey-v1
python3 -m http.server 8765 --bind 0.0.0.0
```

在同一台電腦開啟 `http://localhost:8765/play/`。完整城池配置及原經對讀為 `http://localhost:8765/play/sources.html`。iPad／手機若與電腦在同一個可信任區域網路，可將 localhost 改為電腦區域網路IP（需要作業系統允許本機網路連線）。不要直接雙擊 HTML；ES modules 需由 HTTP 提供。沒有建立公開預覽服務，GitHub 分支檔案頁不是可操作遊戲網址。

首次按「開始旅程」，之後主要按鈕「繼續閱讀」接續位置。每本末頁必須再按「完成這本」，才回饋城景並開放下一本；看末頁、選目錄、重整、回旅程均不會計入。共有29／54／115個原閱讀步驟（198頁），三本完成只表示第一段旅程完成。自由選章另存位置，完成自由閱讀不改依序冊數。原網站其餘11本仍公開閱讀。

## 介面及內容的界線

- `play/index.html`／`app.js`／`play.css`：海島、主要操作、短暫可略過航行、完成回饋、備份／還原／清除確認。
- `play/books.js`：穩定ID、原書路徑與實際既有插圖縮圖。無故事副本。
- `play/reader-bridge.js`／`reader-bridge.css`／`reader-labels.js`：僅 `?journey=ordered|free` 啟用。前三本HTML各加一支module script；不改原稿、內嵌資料、翻頁程式、圖片、漫畫聚焦、經文或獨立模式外觀。遊戲模式重用左上「回簡介」位置為「回旅程」，避免增加固定按鈕遮住橫式口白；原經入口仍可返回導讀。獨立模式維持原「回簡介」。
- `play/city.js`／`city.css`：六門配置SVG、初始加三種回饋狀態，與原書圖片分開。完整配置不受進度遮蔽，清楚標為草圖。
- `play/source-data.js`／`sources.html`：城喻對應與經典／校讀差異；核對證據見 [SOURCES.md](SOURCES.md)。不新增來源未有的教義對應。

## 角色規格與本版實際素材

主角是旅人，並非城主或守門者：橘色虎斑、柔和深色額紋與臉側條紋、米白口鼻臉頰、棕圓眼、粉鼻、圓潤幼貓比例及金黃交領長袍。後續立繪應保持同一臉型、毛色、眼睛、身形、服裝，採水彩童書、紙張紋理、柔和描線與自然暖光。

已實際核對七覺支S11資料與 `seven-factors/assets/11.webp`，與本次參考圖相同。旅程首頁暫用SVG視窗取中央抱念燈籠小貓的既有插畫肖像（引用原檔，沒有改原圖）；不是去背立繪。短過場只用船與念燈籠文字標記，不假稱已完成同一角色的新坐船姿勢。海島與城池是簡單向量／CSS示意美術；暫不複製原圖的兩側火堆、昏沉／浮動與七角色。

待補正式素材：獨立旅人站立／坐船／探索／閱讀立繪、正式海島與城池水彩背景及漸顯差分、經作者確認的五蓋／波旬演出。此版不以待補圖阻擋前三本完整閱讀。

## 存檔、語言與未來擴充

只用 `sutrazen.play.v1`；無登入、帳號、追蹤服務或service worker。`progress.js` 將儲存邏輯與畫面分開，狀態含version、穩定book ID、ordered/free位置、completed集合、目前與依序閱讀的book、重讀中的replayBook、mode及settings。`finish` 僅依序可讀書本明確按完成時計入一次；自由閱讀只存`freePositions`。儲存不可用時顯示說明，當頁仍可讀，但跨頁／重整續讀不保證；資料毀損回到新旅程並說明，還原檔需通過schema及連續完成順序檢查。

備份是旅程JSON，不含經文或私人帳戶。下載可選；還原／清除需確認，清除只移除本遊戲鍵值。沒有 `localStorage.clear()`，不接觸舊繪本站儲存。語言代碼預留zh-Hant、zh-Hans、en、ja，只有繁中完整可用，不顯示未完語言選單。介面集中於i18n.js、reader-labels.js及source-data.js；故事與經文仍由既有各書提供，存檔不依顯示文字。原圖含中文字，換介面語言不代表全書翻譯完成。

之後可更換儲存adapter、加入內容語系及經審核劇情；本版不建立原生App、PWA、雲端存檔或全站快取。

## 驗證

```sh
python3 scripts/check-play.py
python3 -B scripts/build-seo.py --check
git diff HEAD --check -- . ':(exclude)docs/play/canonical'
```

`check-play.py` 使用暫存HTTP與獨立Chromium資料，核對原書頁／分鏡內容雜湊、實際逐頁點按及完成流程、依序／自由模式、存檔／重整／返回、五種尺寸旋轉、獨立閱讀與保護檔案。報告及實際截圖見 `docs/previews/play/`。實體iPhone／iPad Safari及YouTube播放未測，不能將尺寸模擬視為實機驗收。外部來源網域有代理403限制，已讀固定版本原始資料與校勘證據，未宣稱被擋網站直接載入成功。

來源快照保留下載原件的空白與雜湊；差異空白檢查排除canonical目錄，其餘實作檔仍檢查。
