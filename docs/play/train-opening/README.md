## 流程與保留行為

- 群貓背景的三段新字幕仍可自然跑完或點提示進選單；減少動畫時使用原靜態捲讀。主按與設定新增永久2px白框，深色底、淺藍主按字與標題置中保持；plain片頭提示不加框。
- 真正新玩家按開始後才有電車兩段；既有任何positions（含0）、completed、到過遺跡／疑或已完成電車者直接續程。`#opening`重整會在第一段已完全捲出上緣時續第二段；整段完成／略過才記完整呈現。
- 電車只使用一張作者原圖，原圖依視窗cover、重點維持小貓；兩段文字連續由下往上跑，讀完以暖色反光轉入地圖。沒有強制鏡頭放大；視窗旋轉保留crawl比例，背景分頁暫停，減少動畫改靜態。
- 過場只寫既有story seen，不寫book位置、完成或關卡資格。略過及自然結束皆有防穿透；背景可載入／失敗提示及重試，減少動畫可直接轉場，底層inert／焦點管理避免誤觸地圖。
- 地圖工具新增「重看電車過場」：重看不寫seen／閱讀／receipt，返回原地圖。原「重看開場對話」仍可看遺跡對話。
- 四聖諦仍真到末頁後明確「完成這本」才寫完成並發原receipt。新4段尾聲先走完，最後才ack舊doubt-recedes截點、顯示原新增模組／地景通知，再由玩家去城池或下一站。尾聲未走完不能用nav／下一站／Escape跳過。
- 不刪既有Mara scene或其他舊ID，避免舊seen資料整包失效；新主線依最新劇本不經Mara。story schema/key、quota session fallback、journey備份版本與reading store／資格模組保持。
- 活躍模組cache更新`train-opening-1`，resetJourney與storyStore使用同一新版singleton；14原書HTML僅bridge cache，中央reading store模組URL不變。原1192步、全部書稿／引文／插畫、共享讀本版面、首頁心智圖及SEO／Google不改。
