# 十四本收集書架（試做，未發布）

入口 `play/visual-v2/shelf.html`，從本分支根目錄HTTP開啟。此功能承接作者新增「讀完十四本收集破關」的要求；不將閱讀紀錄解釋為證果或斷結。

## 實際操作

未收集的本子採最初書架鎖頭小圖（02–14原SVG；01新法輪標記）。封面本身可點選閱讀，鎖頭僅表示成就未收集，沒有封鎖公開繪本。每本沿用原閱讀器的完整插圖／口白／對應經文；讀到最後一步還須按「完成這本」，才寫入收集紀錄並返回書架。新封面直接使用現有首頁書架對應縮圖，沒有另生替代封面。

讀完任意一本只增加該本，不補完前面書。重讀不重複計數，完成後再重讀可從第一步開始，中途回書架再開啟則接續已保存位置。十四本都完成才顯示「繪本旅程收集完成」。書架沒有測試用的「直接完成」按鈕。

## 模式與保存界線

- 新存檔鍵 `sutrazen.play.collection.v1`，與前三本旅程的 `sutrazen.play.v1` 分離；不刪除／覆寫既有旅程或其他網站鍵值。
- JSON含version、positions（穩定bookID→零起算閱讀步）、completed（去重集合）與activeBook。
- 只有帶 `?collection=1` 的原閱讀器啟用橋接；可另帶 `collectionPage=N` 初始續讀，參數使用後移除，重整採保存位置。
- 十四本HTML各只新增一行module script，其他原稿資料與既有程式不改。獨立開啟原繪本維持原介面。前三本舊journey模式仍保留；URL同時有journey與collection時不重複執行兩套橋接。
- 收藏模式左上重用「回簡介」槽位為「回收集書架」，避免新增固定控制遮旁白。閱讀原經／回修道地圖／本頁經文及原按鍵、漫畫遮黑、縮放／捲動保持。
- 每次真正翻動自動保存，開書、回書架、目錄跳幕、抵達末步或重整都不自動計完成。
- 七覺支是36口白加結語共37閱讀步，以(page,cue)回復；不能只保存12幕或漏掉同圖後續口白。其他本沿用各自實際頁碼，合計1192步。
- 備份／確認還原／確認清除只作用於本收集鍵值。備份格式錯誤保留目前狀態；資料毀損／儲存不可用顯示說明仍可閱讀，跨頁／重整保存不保證。
- 不自動猜測／匯入舊版三本已讀資料；舊紀錄保留，兩模式各自可用。日後若要合併帳本，需明確遷移規格，不以開過書來推定已讀。

## 程式與來源

`play/collection/catalog.js`列14穩定ID、書名、totalSteps、原reader／guide／未讀小圖／現封面。totalSteps是實際核對的導航metadata，不是故事副本；修改原書頁數時需同步並重驗。UI名稱與經文內容分離，現僅繁中完成。

`store.js`為儲存與格式驗證；`reader-bridge.js`為十四種原閱讀器的選用適配，`reader.css`只作用於收集模式。原閱讀器本體不重寫，亦不複製字幕／經文。`shelf.html`／`shelf.js`／`shelf.css`提供書架、封面解鎖與操作。

原小圖／封面的來源與SHA見 `docs/play/visual-v2/thumbnail-inventory.json`；封面未嵌入Base64。新增library-concept.png只是待確認的水彩背景，文字和實際書封是網頁層。
