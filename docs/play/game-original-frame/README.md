# 原圖邊界、底列避讓與港口城池徽章

2026-11-22。作者收齊三張實機截圖後，指出外海藍色接縫與半座城池拼貼不自然，要求按第三張的方式限制移動。從最新 main `0971b459e5c1eab99460ba4ad3cdb75ec6ce2685` 建立 `feat/game-original-frame`，起始工作樹乾淨、origin 正確。沿用遊戲發布授權，經新 PR 合併；精確 merge SHA／Pages／正式站驗收及固定版本 ZIP 以該 PR 交付紀錄為準。

一般探索採原1600×900圖的 cover 最小倍率，可讀區為整個視窗扣除底列實際高度，左／上／右不再留額外海域。鏡頭平移限制在原圖0..1600／0..900；拖到南側極限時，原圖下緣到達操作列上緣，半島仍完整位於操作列上方。底列覆蓋區有單色海藍底襯，接縫只位於列下；它不是可以拖出的外海。

全圖 fit 使用同一原圖邊界，不含先前左200／右200／上140／下220外海。比例不同的視窗以深色中性底襯保留完整原圖，不用異色藍海補邊。全圖拖曳保持全景，縮小不露出新邊界；放大回探索時至少回到 cover 倍率。舊的 scale<.65 判斷改為明確全圖狀態，避免手機短橫式一般海圖被誤判而隱藏地標。

保留左上與底列「返回海圖」、全圖前鏡頭快照、重整／旋轉／舊存檔相容。舊外海鏡頭與返回位置只按新原圖限制做必要修正，不改閱讀進度。到邊界後反向拖曳立即反應，不需先抵銷超出的拖曳距離。單指捕捉移交、防誤開、pinch／cancel 及相機與閱讀資料隔離保留。

移除港口上方半幅城池場景、裁切海岸及跨接短路。原位置改為港口旁的「城池」UI徽章（共享城門圖示＋可替換文字），點擊仍開完整獨立城池；固定底列城池也保留。這是清楚的導航標記，不是宣稱完成新城池插畫。沒有新增城池島、陸地或來源關係，原城景圖與完整六門法義不動。

外海pattern／原圖邊緣alpha混色不再由活動頁載入；歷史檔保留供舊證據及Git對照。原圖PNG逐位元不改、原32地標／46來源關係仍同一座標。根首頁、14本原稿／圖片／經文／閱讀操作、遊戲store／policy／bridge、SEO／Google及Pages main:/維持。QA排除新增本輪後共十三目錄，截圖保留GitHub審閱、不打包Pages。
