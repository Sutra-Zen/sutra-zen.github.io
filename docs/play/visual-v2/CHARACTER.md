# 旅人角色修訂：不持「念」燈籠（2026-11-21）

本文件依作者最新補充，修訂第二輪視覺提案的角色方向。**主角不拿「念」燈籠，也不讓「念」成為整段旅程獨有的象徵道具。** 三十七道品各項都是重要的修習內容；旅人負責陪伴閱讀，不代表其中某一支法，也不代表修學成就。

本輪仍是 `play/visual-v2/` 的獨立視覺提案。第一版可操作原型、三本閱讀內容、存檔與解鎖規則保持原樣；第二輪尚未接成完整正式遊戲，也未部署。第一版當時「抱念燈籠」的素材紀錄是歷史，不要因角色方向更新而把過去實際使用的素材改寫成從未存在。

## 本輪已修正

活動預覽已改用`assets/kitten-rowboat-concept.png`，以雙爪握木槳；原圖生成後已實際檢視，沒有燈籠或念字。`boat()` alt及念字span均已移除，海圖頁腳亦用新船稿。舊kitten-boat-concept.png僅保留歷史，不由活動預覽載入。以下稽核表記錄修正前位置，不能當作目前仍未修正的證據。

## 保留的角色規格

- 橘色虎斑幼貓；額頭與臉側有清楚、柔和的深色條紋。
- 米白色口鼻與臉頰、圓棕眼、粉紅小鼻、圓潤幼貓身形。
- 金黃色交領長袍，衣料有自然皺褶；同一角色的臉型、眼睛、毛色、比例與服裝一致。
- 水彩童書質感、細緻紙紋、柔和描線及自然暖光；適合溪流、花草、森林背景。
- 主角是旅人視角，不兼任城主「識」，也不固定兼任守門者「念」。

## 參考圖使用界線

`seven-factors/assets/11.webp` 與七覺支S11「看火候，調整用功」資料仍可核對作者所指的中央橘貓。**新的角色稿只取臉型、毛色、身形與服裝為參考；不把原圖中抱燈籠的姿勢或「念」字複製成固定角色設定。** 原教學插畫中的兩側火堆、昏沉／浮動及七覺支角色也不因此搬入每個場景。

第一版曾以SVG視窗引用包含燈籠的中央肖像，這是已完成原型的實際紀錄；本次不重畫原繪本，也不把該視窗說成只有臉部的獨立去背素材。後續新稿採「臉型與服裝參考」這一層用途，與舊原型實際呈現分開記錄。

## 新坐船稿的具體要求

- 小貓坐在木船內，以划槳、扶船沿或拿無字書本等中性的旅行／閱讀動作為主。
- 不持燈籠，不持寫有「念」或其他單項法名的旗、牌、珠寶或法器。
- 道具、船身及袍服上不烙入中文字、經號、進度或任務標記；名稱與操作標籤交給網頁。
- 頭頂、耳朵、尾巴、手腳、衣擺、木船與槳保持完整；透明背景需有真正alpha，不以白底冒充去背。
- 圖中的槳或普通書本是旅行演出，不擅自附會為某經典的明文法義對應。
- 若小貓、船與槳仍在同一張扁平透明圖，必須稱「小貓與木船合併概念素材」，不能宣稱已取得獨立空船、可分別擺動的手臂與船槳圖層。
- 新姿勢仍待作者確認角色一致性。未核定概念素材不自動升格為正式角色稿。

### 必須保留的「念」與光影

`play/visual-v2/data.js` 的 `guardian`／「守門者・念」是SN35.245城喻固定對應，**應保留**。這個角色與旅人分開；不能因主角不再拿燈籠而刪掉守門者的念，或改成沒有經典依據的角色。

城門暖燈、螢光、水面反光可繼續作閱讀進度的美術回饋。CSS動畫名稱若叫 `lantern`，本身不構成主角偏重念的法義表達；如改名應只改善命名清楚度，不誤刪城池光影。新角色不持提燈與城池保留合理照明是兩件事。

## 新稿交付時的核對

1. 全景、船隻近景及回饋演出均沒有旅人持「念」燈籠或殘留的HTML念字。
2. 角色仍與作者中央橘貓的臉型、毛色、條紋及金黃長袍相符。
3. 六門城池的念守門者、止觀使者與其他經典對應維持，旅人與他們可明確區分。
4. 活動頁的alt、素材manifest、README及圖像實際呈現一致；舊稿保留時清楚標示歷史。
5. 背景透明度、完整比例、窄螢幕縮放與減少動態模式另行實測；本文件不冒充已完成新圖片或實機驗收。
