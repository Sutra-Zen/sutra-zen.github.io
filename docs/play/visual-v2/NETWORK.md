# 原心智圖的完整節點與連線資料

本輪只抽取原圖資料與提案場景使用座標，不改根目錄首頁、經文或現有閱讀器。`play/visual-v2/network-data.js` 是本輪視覺版使用的可檢查資料，不是新的法義論證。

## 來源與實際數量

來源是目前根目錄 `index.html` 中 `main.sz-map-scroll` 的DOM、原SVG道路分支／返回線、四條橫列和五族直欄的CSS連接線，以及同檔 `dhammaData` 的實際資源連結。基準main為 `b9a0dad2c2c34d7e15e6dc5e55d6125de630f57b`；首頁檔SHA256與測量條件存在`NETWORK_SOURCE`。

原圖有32個不同的modal key，33個可點視覺位置。差一個的原因是「八正道總說」同時出現在左側總說欄與四聖諦「道」的右下按鈕；兩個位置開同一份內容，不能因此算兩本書或兩份進度。

在1600×1000 Chromium視窗，以既有Tailwind及Lucide副本載入首頁，實測原地圖內容框1300×608。每個可點元素的中心、寬、高都保留於`NODES.originalPositions`；`INSTANCES`的33個x/y就是這些位置換算為原圖百分比，沒有把原網路排成新創的十四個等距關卡。展示畫布可以等比例放大或加高，原節點間的橫列／直欄仍保留。工程擷取圖另存於本工作區 `/tmp/play-original-map-network.png`。

## 資料介面

- `NODES`：32筆。穩定英文`id`、原`key`、原modal標題`title`、適合顯示的`label`、五族`family`、主位置百分比`x/y`、既有`bookId`、導讀`guide`、繪本`reader`、原影片`video`及全部原位置。標題是顯示資料，存檔仍使用穩定繪本ID。
- `INSTANCES`：33筆。各有穩定instance ID、所屬`nodeId`、原始DOM序號與百分比位置。`eightfold-overview-main`是總說欄，`eightfold-overview-four-truths-port`是四聖諦「道」旁的第二個視覺入口。
- `EDGES`：46筆原圖關聯紀錄。每筆`from/to`指向32個node ID；`fromInstance/toInstance`指向原視覺位置，必要時以`fromGroup/toGroup`指明原本是連到整個多按鈕方框。每筆有`kind`及DOM／CSS／SVG來源`provenance`。只有原「道」返回「道路」的線有方向箭頭；其他關係不加修證先後箭頭。
- `GROUPS`：原相關內容欄五個框的成員與實測邊界。四不壞淨／六念、四念處／四顛倒、四正勤／十善、安那般那／四如意足／四禪，以及四聖諦內部，是原本共用方框的元素，不能不加說明地把它們當成新增教義邊。
- `READING_ROUTE`：十四個不重複繪本ID的探索建議；`BOOK_WAYPOINTS`將它們對到實際節點。這是提案的閱讀路線，不是原經明訂的次第，也不改第一版前三本的既有解鎖邏輯。

導讀及繪本網址逐一從原`dhammaData`三張資源卡取出，改為相對`play/visual-v2/`可用的`../../...`路徑；沒有猜測新頁名或新經號。道路／相關內容總說保留原書架總覽入口，其餘子節點沿用目前對應書籍，不另複製繪本。

## 鏡向L形探索路線的界線

第一版入口仍從右下四聖諦與苦／集／滅／道對讀群開始；接著可以往左探索底部定、勤、念、信的主題群，再往左上總說群。這是畫面上的「右下→底部往左→左側往上」引導，不是將所有節點線換成同一條強制單向鏈。

十四本建議路線先保留四聖諦、五陰、六處三本，再列十二因緣、四向四果、八正道、安那般那、四如意足、四禪、四正勤、四念處、四不壞淨、七覺支、五根五力。作者仍可調整後續十一本文獻的探索順序；不把這個列表稱為修證次第。八正道的閱讀路標可使用四聖諦內的第二個視覺入口，不能因為唯一node的主位置在左欄，就多創一份繪本完成紀錄。

## 主角與原站保護

新旅人不再以抱「念」燈籠的姿勢作唯一身份；角色、道具和船姿依本輪作者新指示另行美術核定。城喻的守門者「念」與旅人維持不同角色。這份網路資料不改原站十四本圖片、字幕、經文、來源、SEO或首頁導覽，也不表示提案已發布。

## 實際展示座標與避讓

network.js的DISPLAY表另設群島顯示間距，並留畫布安全邊；NODES／INSTANCES只保留原圖實測位置，不再當作島體尺寸足夠的假設。四聖諦內部從原小方框展開為可分別點擊的小島，避免五陰與六處重疊；定群三島亦拉開。連到原共框的橫線／直線使用群組中心或上緣接觸點，並以data-from-group／data-to-group保留該區別。這是視覺避讓，不是新增法義線。
