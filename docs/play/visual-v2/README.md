## 最新修訂：互通海圖與中性旅人

依作者最新說明，預設畫面改成「互通海圖」：以原心智圖的32個主題、33個顯示入口及46筆連線／群組關係建立小島網絡。32個主題仍連到原專頁與繪本；八正道重複入口不重複建立一本書。閱讀航線從右下四聖諦、苦的五陰六處、集的十二因緣出發，沿整體反向L方向走向左上五根五力／七覺支；這是閱讀安排，不是修證先後或新的解鎖條件。

較淡水路保留原圖的橫向／縱向對讀與群組關係；點四念處或「看念的互通」會亮起念根念力、念覺支、正念、四念處等節點，可由彈窗直接跳到相鄰主題或原專頁。全部原圖位置與連線來源留在network-data.js供核對，畫稿為避免島體重疊而調整間距，不宣稱逐像素複製原DOM。

主角新稿改成握木槳的小橘貓，不抱燈籠，也沒有旅人道具上的念字；原七覺支圖只作臉型、毛色與服裝參考。城喻中「守門者＝念」是另一角色的經典對應，照常保留。詳[角色修訂](CHARACTER.md)、[網絡來源](NETWORK.md)、network-generated-assets.json。

新增3份概念資產：中性划船小貓、四種透明小島圖集、水彩海面。舊14島全景保留在「原構圖」比較分頁，但活動場景的小貓全改用新船稿；舊燈籠PNG只留作歷史提案，不再由預覽載入。下列14島初稿說明屬先前構圖，預設新海圖以32主題為準。

## 直接試閱

從此分支專案根目錄執行：

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

開 `http://localhost:8765/play/visual-v2/`。點「互通海圖／原構圖／城池／完成回饋」切換場景。手機可滑動畫布、定位前三島，或切換「只看全景」。無公開預覽服務；此為本機HTTP驗證，不宣稱 `https://sutra-zen.github.io/play/` 或此子路徑已上線。

1. 群島採一張有森林、溪流、花草、暖光與城池的水彩全景；十四本以十四個HTML主題標記連到既有心智圖的相關主題。只有前三座島示範本次閱讀順序，其餘十一座明示「後續旅程，原書已可讀」。圖中裝飾小礁石不另算主題。可開啟「心智圖關聯」對讀其關係，不宣稱十四本是一條修證順序。
2. 未讀標記引用初版書架commit `6aaa1af` 的十三個原SVG；四聖諦原本沒有同系列小圖，另以法輪作HTML/SVG標記。先點島，再顯示閱讀／導讀操作；沒有用三張矩形卡片代表島體。
3. 城池改用具六門、道路、房屋、廣場與草木的水彩場景。十三個探索點涵蓋六門及七組說明（止觀使者合為一對）；詳細文字只在點擊或法義索引打開。原幾何配置圖與經典對讀保留在 `../sources.html`。
4. 完成回饋讓木船小貓回到城池；讀完一本文字／道路光、二本透明花草增長、三本六門燈光與螢光可分別預覽，接著「繼續旅程」。不是淡色工程圖。
5. 所有狀態切換都是**審稿用演出控制**，正式接入後應由真實閱讀進度驅動，不會把這些按鈕當作正式遊戲的完成捷徑。本預覽不匯入progress模組、不寫入localStorage，試讀原繪本也不替原型偽造完成。
