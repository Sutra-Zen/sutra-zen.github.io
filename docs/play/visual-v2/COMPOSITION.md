## 從現有心智圖取出的關係

已讀取根目錄 `index.html` 的實際地圖DOM及節點入口，而非依十四本書架順序猜圖。現有圖的「道路」連到五根五力、七覺支、八正道與相關內容；橫向五族為信、念、勤、定、慧：

| 圖上的族群／對讀關係 | 對應本次十四本 |
| --- | --- |
| 信：信根信力與四不壞淨、六念 | 第07本四不壞淨與六念 |
| 念：念根念力、念覺支、正念，連四念處與對治四顛倒 | 第08本四念處與四顛倒 |
| 勤：勤根勤力、精進覺支、正精進與正語正業正命，連四正勤／十善 | 第09本四正勤；第05本八正道與十善業道 |
| 定：定根定力、喜輕安定捨、正定，連安那般那／四如意足／四禪 | 第10、11、12本 |
| 慧：慧根慧力、擇法覺支、正見正志，連四聖諦 | 第01本，以及苦→五陰／六處、集→十二因緣、滅→四向四果、道→八正道 |
| 五根五力／七覺支／八正道總說 | 第13、14、05本，連回同一修道地圖的不同對讀面向 |

因此新世界不是「十四本一圈依序打關」，也不是十四棟房子。各島保留原圖的主題群聚；遊戲唯一明確的第一版閱讀箭頭是四聖諦→五陰→六處。其他細線表示相關主題，不能讓讀者誤以為是新的修證先後次第。

## 世界圖熱區與手機視窗

- 原圖完整比例顯示在可平移的地圖容器，不以`object-fit:cover`裁掉島嶼；手機不把整幅3600寬的世界硬縮成360寬。
- 手機可先以約1440 CSS px寬的完整畫布呈現（母圖的0.4倍），視窗定位於前三島海灣；三島中心跨度約184 CSS px，加島岸後仍能在一個約360px視窗中辨認。其餘世界可用原生左右／上下捲動查看。
- 主要「開始旅程／繼續閱讀」在地圖外固定的正常文件區，讀者不必先尋找或拖動地圖才能閱讀。平移是探索的次要操作，不變成必學關卡。
- 每島可點熱區以島體及碼頭為基礎：建議母圖中心周圍寬360、高260的圓角區。實際顯示時按鍵命中區至少48×48 CSS px；不讓細小鎖頭承擔唯一可點範圍。
- 島名與狀態用HTML放在島旁安靜水面，維持至少18–20 CSS px，文字可換行。各島名稱不隨整幅底圖一起縮成小字。未解鎖第一版島附鎖頭，但可由清楚文字理解順序。
- 後續十一島可檢視名稱與「後續旅程」，提供前往原書架入口；不自動開放依序旅程，也不改原站十四本公開閱讀。
- 在世界視窗旁提供可用鍵盤操作的三本清單與「查看城池」入口；地圖本身要能捲動、縮放及回到目前島，不以禁用瀏覽器縮放解決。
- 圖層座標以完整畫布比例儲存；不要用整個螢幕百分比定位島名。裝置旋轉維持目前閱讀位置與最近探索區域，不以旋轉重置存檔。
