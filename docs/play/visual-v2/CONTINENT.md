# 底部長陸地與主題群山提案

本次只調整獨立視覺提案的地景表達，不改原首頁、原繪本、法義對應或第一版存檔。依作者最新指示，「相關內容」不再是一座可點小島；原底部五組主題改為同一片長陸地上的群山。所有山峰以水彩畫稿呈現，不再由小島輪廓冒充山形。

## 節點與原圖關係怎麼保留

- 「相關內容」只作長陸地的區域標題，可用`h2`或普通HTML文字，沒有鎖頭、圖示、`button`、`tabindex`或另一份完成紀錄。
- 移除的只有這一個可點總說入口：畫面從32個不同節點／33個可點位置，改為31個不同節點／32個可點位置。八正道仍保留左側總說及右下「道」的兩個入口，共用同一節點／繪本ID。
- 原`network-data.js`的32-key擷取資料可以繼續留作來源紀錄；展示層過濾`related-overview`。不能為了讓數字相等而刪掉原圖的其他子題，也不重新寫首頁。
- 原「道路→相關內容」分支，改作道路連到長陸地入口的地理關係；原「相關內容→四不壞淨／六念共框」改由同一區域的西端支路承接。來源可註明已轉成非互動區域接點，不在畫面留下看不見的可點島。
- 信、念、勤、定、慧的直欄，以及各橫列對讀仍接到原群組。原共框改為同一山腳的群山，不將共框成員誤畫成新的修證先後。

## 山形畫稿與素材建議

根據各區可使用四類一致畫風的圓潤山形：有溪流的寬緩峰、樹林雙峰、石徑高低三峰、帶小書亭的山麓。種類只調整風景與構圖，不把峰高當成修證高低。所有峰都有真正的坡面、山脊與山腳，避免沿用島岸、碼頭與海水環。

- **連續長岸母圖**：建議2800×1000以上透明PNG／WebP，保留連續草地、岸線、沙灘及安靜路面。畫面上緣依五個族群伸出不同緩丘；圖內不畫主題字、不放鎖頭或完成徽章。若生成圖已混入峰群，不聲稱它又是一套能獨立移動的正式峰層。
- **透明山形圖集**：可先做2×2圖集，每格至少800×600，四周留足透明間隙。峰頂、左右山腳與陰影完整，不把相鄰山形黏成無法切分的圖。正式上站前再核對每格裁切與透明邊。
- **定的三峰群**：建議獨立1400×1000透明概念稿，三峰同角度與光源；若用圖集組出，山腳要接合自然。概念稿可先是一張圖，不能因此宣稱已完成三峰各自的正式圖層。
- **連線與地景分層**：原圖對讀線仍由SVG繪製；群山、陸地和散步道不烙進主題文字。讀者選取後的光線與圈選也由網頁呈現。

這些是本輪水彩視覺試作的素材要求，作者未核定前仍標為概念圖；既有城池工程配置與原始連線擷取資料都保留。

## 右下「道」到左側道路入口的自然回路

起點使用右下的`eightfold-overview-four-truths-port`，不是左欄`eightfold-overview-main`。目前右下「道／八正道」約在(80.8%,90.24%)；同一節點的兩個位置只是一份內容與進度。

路面由這個起點往南微彎，沿長陸地的前緣往左，經定、勤、念、信各山腳，再在西端順岸向上，抵達原「道路」入口約(10.4%,41.84%)。路是接合地景的暖土色散步道，不使用直角折線、虛線金條或大箭頭把整個畫面圍成關卡框。

建議曲線控制區域為：起點(80.8,90.24)→東南彎(75,94)→中段(57,94.5)→西段(33,94)→西端彎(23,88)→左側海岸步道(16,73)→道路入口(10.4,41.84)。這些是構圖控制區而非必須踩中的中途關卡，後續依岸線避開人物與標籤。

西側若仍隔著海水，就補一座短木橋／石橋，或讓長岸在西北端伸出自然陸橋；不能把陸上散步道直接畫在海面上。橋只作景觀過渡，讀者不需操船或手動走路才能繼續閱讀。與原圖返回線同義的回路可低調保留方向提示；其他對讀線不加修證先後箭頭。

## 互動與驗收界線

1. 可見可點位置應是32個，去重後31個key；「相關內容」只剩區域標題。
2. 底部是一片長陸地，十五個主題位置表現為山峰或山麓入口；不能仍像一排分離小島。
3. 安那般那／四如意足／四禪是近距離三峰群，各自可點且標籤不重疊。
4. 道的返回路沿地面自然抵達道路入口；主要閱讀按鈕仍在地圖外，無須學習走路、拖曳或操船。
5. 原圖其他節點、橫列／直欄與共框關聯保留；轉成區域接點的兩段來源另作註明，不假造新的法義連線。
6. 手機保留整張畫布的平移檢查，不能為了縮覽把山峰標籤壓成細字；至少另檢查原比例平移模式下的熱區命中。
7. 主角繼續使用本輪划槳旅人方向，不重新加回「念」燈籠身分，也不兼任城喻守門者。閱讀完成的回饋另列於既有旅程進度，不與峰高、發光或城池修整混成證果宣告。

本文件本身不修改任何腳本或網頁；新的長岸、山圖集與展示層調整由主工作分支另外實作與檢查，未發布。
