# 獨立城池入口與定區交通線修正

本輪延續尚未發布的繪本旅程試作。新增的城池頁為 `play/city/`，與山海地圖及完整閱讀器同站並存；不替換正式首頁、不修改原經或書籍圖片，不把這一輪視覺／互動調整當成正式部署授權。

## 港口到四禪的斜線從哪裡來

它不是原始資料新增了「港口→四禪」的教義關係。原資料 `play/visual-v2/network-data.js` 中，來源邊 `overview-branch-road-overview-eightfold-overview` 是「道路總說→八正道總說」，而且沒有 `fromGroup`／`toGroup`。

新版世界地圖把 `road-overview` 顯示為港口(128,423)，同一 `eightfold-overview` 的第一個顯示地標是右下驛站 `path_station`(1480,693)。原本 `sourceLines()` 仍對這條邊採直接兩點直線，形成 `M128 423L1480 693`。當x=1152時，線的y約627.50；四禪地標正好在(1152,630)，因此斜線看起來直接接到四禪。這次不是定區群組接點造成，而是同概念多地標取第一個錨點、再畫直線的展示結果。

簡單說：**原「道路到八正道總說」的線被拉到右下新驛站，直線剛好穿過四禪旁，看起來才像港口連四禪。**

## 本輪怎麼處理

依作者確認的顯示方向，讓定區交通線按「四禪→四如意足→港口」經過。幾何展示與原圖教義關係分開：

- 原 `EDGES` 46筆來源紀錄、ID及端點不改。前述港口／驛站來源邊沿既有下方半島公路 `GEOGRAPHIC_ROAD` 繪製，仍是原來的兩個來源端點，不再穿越四禪。
- 額外的定區小徑在獨立 `MAP_CONNECTIONS`／展示交通資料中記錄，經四禪(1152,630)、四如意足船塢(1152,531)、港口(128,423)。它是作者本輪指定的地圖交通／視覺動線，不回填為新的經典或原心智圖 `relations`。
- 同欄主題與原對讀連線繼續保留；不把展示小徑說成「先修四禪才可修四如意足」的教義次第。
- 推薦閱讀 `routeOrder` 不因這條顯示小徑改動：四如意足仍第10、四禪第11。完成計數仍依固定book_id集合。

## 獨立城池頁的操作方向

海圖旁提供固定可辨識的城堡圖示與「城池」入口。城池採獨立16:9世界場景，保留全幅構圖與可讀文字；手機與平板不強制螢幕旋轉。點城門、城主、守門者、雙使者、廣場、消息或道路，顯示簡短法義與相關繪本重讀／對讀入口，不把整段來源說明常駐壓在畫面上。

完成繪本後主要操作仍是繼續下一本；城池是次要的可選入口，不再把大型城景嵌入每次完成回饋、迫使讀者先看城。城池隨時可以回來看實際進度，不需要為看場景而重讀已完成書。

本輪城主保留橘虎斑小貓、皇冠與作者要求清楚可辨的鬍子扮相。角色造型是美術設計；城主在SN35.245城喻代表「識」，不代表永恆靈魂、真正的我或操縱所有身心活動的不變主宰。念守門者、止觀雙使與旅人是不同敘事角色。

## 進度與來源保護

- 城池從既有 `sutrazen.play.collection.v1` 完成ID集合推導；不以畫面按鈕、看城、重播或略過動畫增加完成數。
- 城體依五陰、六門依六處、念守門者依四念處及實際擺放前置、止觀雙使依安那般那與前置條件。已取得但尚不能擺放的角色可先預覽，補齊後自動安置。
- SN35.245的六門版、四大廣場、城主識、念守門者、止觀雙使、涅槃消息與八正道路不改；漢譯1175仍另作平行對讀。
- 原十四本讀本內容與正式末步「完成這本」事件不改。所有新增返回／重讀入口仍使用原網址與必要的選用進度參數。
- 新圖只表示待作者確認的概念素材。新城圖 `play/visual-v2/assets/city-moustache-concept.png` 原生1672×941、RGB，與生成輸出逐位元相同；實際尺寸、SHA與來源見本資料夾 `generated-assets.json`。它是接近16:9的全幅概念畫稿，並非原生4K；不能把尚未拆層的整張畫稿稱為完成的獨立角色動畫。

## 試閱與驗收

從此分支專案根目錄執行 `python3 -m http.server 8765`，本機開啟 `http://localhost:8765/play/worldmap-v4/` 及 `http://localhost:8765/play/city/`。前者是山海地圖，後者是獨立城池。這些是本機試閱路徑，不是正式站已發布網址。

實際整合以 `play/navigation.js`／`navigation.css` 共用固定導覽，順序為海圖、心智圖、城堡圖示＋城池、書架；新世界地圖、獨立城池、舊視覺提案及收集書架共用正確的模組相對網址。完成回饋由 `play/worldmap-v4/completion-feedback.js` 提供小型獎勵圖及文字，主要按鈕接續下一本，次要「看看城池」另開獨立頁；不強迫先看大型城景。

獨立本機檢查已實測360×800與1024×768：四個導覽順序／網址及至少44px點擊範圍、14個部件說明與重讀入口、所有說明沒有 `[object Object]`／`undefined`、審稿切換不寫完成存檔，均通過，無JS錯誤或外部水平溢出。靜態核對原network-data逐位元保持；SVG保留46個來源邊，另外一個 `data-display-route` 明標非來源關係；問題來源邊實際沿半島公路，不再畫原斜線。

完整操作與更多尺寸由 `scripts/check-play-city-entry.py` 及本輪 `docs/previews/play-city-entry/` 報告記錄，只有實際執行的結果可回報通過。實體Safari與原生裝置手勢尚未驗收；獨立場景美術仍為概念稿，不把桌面模擬當作實機或正式美術核定。
