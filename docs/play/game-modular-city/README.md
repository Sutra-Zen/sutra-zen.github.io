## 可操作流程

閱讀末頁明確「完成這本」仍是唯一主線完成入口。閱讀回饋會顯示**已取得新模組**，可繼續下一本，或從固定底列進城安置。城景安置不增加已讀冊數，也不影響下一本閱讀資格。

第一本完成後，草地上先有四大花園與識城主，周圍有波旬、貪欲、瞋恚、昏沉、掉悔與疑。碼頭、城界、六門等由玩家安置；舊玩家的已讀紀錄保留，已取得的模組不會自動當成已安置。

「安置模組」展開14張清單：未取得反灰、已取得待安置變彩色；點卡片後按對應「＋」、把卡片拖到「＋」，或使用單組／全部已取得的自動安置。六門是一組六個固定門座；已放置模組可點選認識、查看來源及複習已讀本。缺少前置設施時保留取得狀態並提示先放哪一項。末章模組沿用原本的揭曉條件。

## 角色與心聲

五蓋完整圓球圖用CSS由−3°緩慢搖到＋3°；波旬使用新增的完整漂浮全身、空手無面具圖；原故事對話頭像逐位元保留。識城主另疊真正鬍鬚圖層，嘴被覆蓋，兩顆汗滴循環出現／消失。安置念後，角色移到花園外圍、城主汗滴間隔放慢，角色沒有因讀完／安置而被永久消滅。

點角色或「城裡的心聲」會開啟屏幕座標的深色半透明對話；可切換角色或收起，鏡頭縮放不縮小文字。首次進城有城主心想；安置六門但尚無念時，波旬說「哼，門蓋得倒漂亮，卻連個看門的都沒有！」。念與使者另有短句。文字集中`thoughts.js`，與經文、原書口白、原map劇情分開；既有閱讀過場保留。

減少動態偏好會停止搖擺、浮動、光暈與汗滴。所有角色是彩繪靜態圖件的輕量演出，不使用需要玩家操作的戰鬥或尋路關卡。

## 程式與保存

- `play/city/modules/catalog.js`：14個穩定reward ID、世界1600×900固定插槽、免費底盤及前置條件。只保存ID，不保存語言或viewport像素。
- `modules/store.js`：`sutrazen.play.city.v1`，格式`{version:1,placedIds,thoughtSeenIds}`；session備援為`...city.session.v1`，以canonical `baseRaw`作界線。取得由原completed唯讀推導；已取得／可安置／已安置分開，歷史缺前置保留，無自動補讀。
- `modules/scene.js/css`：真透明atlas的SVG viewBox、獨立鏡頭`...city.camera.v1`、點選／拖放、清單橫滑、角色與汗滴。每張atlas有實際裁窗clip，避免相鄰角色漏出；沒有修改來源PNG。
- `modules/art.js`與[ART.md](../../../play/city/modules/ART.md)：美術原件、hash、裁窗、來源與限制。所有新增標籤使用HTML，沒有烙進新圖。
- `city.js`、`thoughts.js/css`：閱讀續接、來源視窗、安置事件、屏幕心聲。六門主城仍以SN35.245為準，SA1175平行差異保留於既有原經對讀；城體／四大廣場／識／念／雙使／消息涅槃／道路的對應可點選。
- `play/journey-save.js`：統一設定與作者重置，備份`{format:'sutrazen.journey',version:2,collection:<原v1>,city:<cityv1>}`。所有區塊先純驗證才落盤；舊collection-only v1仍接受，但重置城市配置，避免帶入另一存檔的佈置。新備份保存閱讀與城市，不把動畫播放當成完成。

兩個重置入口同時清除遊戲reading／city／route／story／receipt及遊戲鏡頭session，保留原網站、舊原型與其他keys；不用`localStorage.clear()`。還原及重置會通知地圖／城池關閉舊對話、清選擇並重算畫面。全禁儲存時當頁仍可閱讀／安置，明示非永久保存；city獨有故障不冒稱讀書進度也壞掉。

## 舊站、產生器及發布

根首頁、`#map-heading`、十四本原正文／插畫／經文／操作、十五頁SEO、sitemap／robots／Google驗證均保留。14本HTML各只改既有collection bridge的快取query，正規化唯一URL後全文須等於基準；bridge只改返回新版遊戲的query。裸原讀本網址仍完全自由閱讀，不套城池介面。

入口及互返query為`modular-city-1`；故事store仍共用未變的`mara-1`資料實例。`play/worldmap-v4/index.html`與`build-game-entry.py`產生的`game/index.html`同步。Pages仍legacy `main:/`，只新增QA排除目錄，合計十九個，沒有改發布來源。
