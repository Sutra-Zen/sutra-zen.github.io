海圖視口改為 `inset:0`，寬高等於可用瀏覽器視窗；背景繼續顯示在底部操作列後面，不再被上方進度區、下方導覽留白縮小。地圖／城池／書架、續讀＋頁數、已讀進度、目前關卡、全圖、＋／－、工具與設定共用單列半透明 dock。桌機及平板橫式全列可見；窄螢幕保持字級與按鍵，列內可左右滑動，另有 48px 箭頭與邊緣漸隱提示。這是局部橫向捲列，不會讓整頁水平溢出；鍵盤 focus 自動帶出目標。

`game-shell.js` 新增 `mountMapControls({primary,tools,menu})`，把來源 DOM 移入同一列，而非複製按鈕或另存進度。工具使用原生 dialog 從底列上方展開，避免被橫捲列裁切；選路線後先關工具再顯示主題／鎖定說明。城池與書架沿用同一底列，但可捲動內容仍留足操作列高度；原繪本不載入此殼、經文及閱讀按鍵不改。

相機修正真實單指拖曳問題：觸控從地名標牌開始時，瀏覽器原先隱含捕獲該子元素；拖曳移交視口時，子元素的 `lostpointercapture` 冒泡被誤判為取消，導致只移動第一小段。現在只處理視口本身真正失去捕獲的情況，保留取消清理、拖後防誤開及雙指縮放。未用全站禁止縮放或移除標牌點擊解決。鍵盤定位鏡頭外地標時會帶到可見區並避讓底列，pointer點選不先移動其目標。

港口城池以 `harbor-castle.js/css` 重用既有城景 PNG 與鬍鬚圖層，不修改／重生原圖。世界圖座標完整微縮圖寬 360，高約203；左半放到 x=-180，從世界左界只露右半，城門有短路連向港口。裁窗、圖景及道路跟同一相機變換；HTML 標牌及觸控區保有可讀／可按下限，沿用 `data-wm-city-entry` 進相同城池。它是展示入口，不新增法義／原圖關係或第十五本。

首頁紙卡與標題以 flex 在安全區內水平、垂直置中，短橫式可在卡內捲動，保留原始作者 JPEG、HTML 主標／副標與開始／繼續行為。未改品牌、文案或存檔。
