# SutraZen 大地圖地景精修規格

版本：2026-11-22-map-v4

用途：把既有互通海圖精修為「上方兩排概念群島、中段繪本大陸、下方八正道公路半島」，供 Codex 在既有試作上優化。

本版取代 map-v1、map-v2、map-v3 的地圖構圖與地景配置，補充閱讀路線規格 2026-11-22-r3。十四本閱讀次序、book_id、原網站網址與城喻對應維持不變。檔名沿用舊名稱，請以本行版本與內文為準。

## 1. 本輪方向與範圍

- 世界畫布採 16:9，統一使用 `viewBox="0 0 1600 900"` 或等比例世界座標。
- 上方只留兩排群島：更北的上排為第 13 本七覺支，靠大陸的下排為第 12 本五根五力。兩排完整地標、標牌與卷軸對調，讓從大陸出航的閱讀旅程先近後遠；十四本閱讀次序與原概念資料不變。八正道仍為下方狹長半島的公路、橋梁與右下驛站。
- 上方群島、中段地景、下方橋梁依使用者提供的原心智圖，同用信、念、勤、定、慧五個縱向欄位。
- 正精進、正語、正業、正命放在同一橋群、同一組標牌。喜、息、定、捨覺支放在同一緊密島群、同一組標牌。
- 中段地景縮小到足以保留縱向對應與海面留白，透過湖灣、森林、花田、山谷、遺跡及碼頭辨識每本書。
- 本文件規劃全十四本地圖；可玩試作沿用已核定範圍，目前以前三本為起始試作。完整美術規劃不表示十四本互動皆已完成。
- 本輪不改根目錄、原心智圖、既有繪本網址及發布流程；在既有 `/play/` 範圍優化。

最新版有字概念圖用來確認美術、地形、名稱與分組。正式節點錨點依本文件與原心智圖資料實作，不以生成圖的像素位置當成精確座標。較早的三排群島、八正道山、旅人驛站構圖已被本版取代。

本輪提供兩張同構圖概念圖，將兩排群島連同標牌、卷軸完整上下對調；五欄 x、大陸與橋梁位置固定不變。正式實作以本版五欄共同座標為準，不能讓上下各自累加位移。

- 兩版必須沿用同一底圖構圖、比例與地標位置，皆採七覺支上排、五根五力下排，並保留相同的「八正道公路」新卷軸；不能重新散排島嶼或橋梁，才能直接比較有線／無線的閱讀效果。

圖上連線只示意視覺對齊與既有群組關係，不作新增 relations 的資料來源。正式網站以 SVG／HTML 疊加原心智圖連線，保留可開關的文字與線層；不將概念線烘焙進正式底圖。

## 3. 八正道公路半島與交通起點

### 3.1 完整道路

東南大陸的「道諦-八正道驛站」經短橋或引道接到下方半島東端。由右向左沿路依序經過：

1. 正見／正志橋，位於慧欄。
2. 正定橋，位於定欄。
3. 正精進、正語、正業、正命橋群，位於勤欄。
4. 正念橋，位於念欄。
5. 無具名節點的沿海公路，西端向上轉入「三十七道品海陸港口」。

這條路呼應原心智圖下方由道諦通到左側道路入口的深藍連線。它是交通與概念組織的美術表現，不是新的十四本閱讀排序，也不要求按橋梁順序操作才能過關。

正精進、正語、正業、正命使用一個完整群組範圍與共同標牌，可分兩行排字或畫成相連小橋。不能把正語、正業、正命移到另外三座島，也不能只保留正精進。展開面板仍可逐項顯示原概念及關係。

### 3.2 新舊地景替換

- 驛站正式名稱為「道諦-八正道驛站」，主題地標歸 eightfold-path。採木造驛站與馬拉木製車廂，保留親切童書風格；不使用現代巴士，也不新增必需操作的交通系統。顯示名稱與交通美術更新，path_station 等既有 ID 及存檔不變。
- 三十七道品海陸港口是共同導覽設施，不是第十五本。可提供繼續閱讀、查看旅程、回城池、登船查看概念島等入口。
- 移除八正道山及其標牌、熱區；移除上方八正道總覽島與因素島排。原八正道因素由半島橋梁承接，保留原概念關係與進度。
- 舊「旅人驛站」由新驛站取代，不同時保留兩個功能相同、名稱不同的交通起點。
- 十善業道湖仍在勤欄，鄰接四正勤花田。小溪可由普通山坡或泉源流入，不再造具名八正道山。

基本公路輪廓及導覽入口在未讀時仍可見、可用。讀完八正道書後，驛站裝飾、橋梁標牌、公路光色、溪湖景觀一併活化；未讀時不封死閱讀入口。

### 3.3 半島西段「八正道公路」卷軸

在半島西段沒有概念橋的路旁加入「八正道公路」卷軸，範圍約 x 15%–31%，中心 x 23%（368），y 約 84%–85%（756–765）。依海岸微調留白，不遮住道路、海陸港口或 x 42% 的正念橋。

卷軸文字與 path_road 同組，屬於同一本 eightfold-path；它是既有道路的標題，不是新關卡、新橋或獨立解鎖項。不增加閱讀進度，不加入額外概念連線。若可點擊，沿用原八正道書籍入口即可。有線與無線兩版都保留此卷軸；正式版仍以可翻譯的網頁文字層呈現。

## 6. 三種連接分開管理

1. 地理道路與水路：半島公路、橋、河流、小路、碼頭，屬世界美術與交通。
2. 推薦閱讀路線：由 routeOrder 決定，以淡金引導或小貓提示下一本，維持本文件十四本順序。
3. 原心智圖關係：由既有 relations 決定，選取時顯示直接相關細線，保留全部互通連線查看功能。

半島由右往左的橋序不重排十四本閱讀順序，也不將正念、正定等拆成額外書籍。公路造型呼應深藍連線；其語意與資料仍依原心智圖，不因地理方便新增或刪除關係。

選中同一本的任一地景時，其餘地景可同步柔和提示。例如選十善業道湖，可提示驛站、半島公路與橋，面板顯示「八正道與十善業道」。不能把四正勤花田一同標為完成。

## 7. 完成狀態與資料結構

沿用現有架構，分開保留：

- book_id：繪本、閱讀位置與完成記錄。
- landmark_id：地理地標，一本可對應多個。
- concept_id：原心智圖概念，即使同組標牌也保留個別 ID。
- visualGroupId：可選排版分組，例如四因素橋群、喜息定捨島群；不取代原概念 ID。
- relations：原心智圖關係；閱讀路線另以 routeOrder 管理。
- combinationScenes：跨書回饋與 requiredBookIds。

八正道書的歸屬示例：

path_road.bookId = eightfold-path
path_bridge_wisdom.bookId = eightfold-path
path_bridge_concentration.bookId = eightfold-path

path_bridge_mindfulness.bookId = eightfold-path
path_stream.bookId = eightfold-path

四因素橋群包含正精進、正語、正業、正命原概念 ID，群組錨點在勤欄。喜息定捨島群也保留四個原概念 ID，群組錨點在定欄。「同一地圖群組」不等於「四項彼此等同」。

移除舊八正道山、島排的視覺物件與熱區時，保留 eightfold-path 既有存檔。新站、公路、橋、湖接續原閱讀位置與完成狀態，不重置、不重複計數。

completedBookIds 是唯一完成集合。大地圖、概念群島、書架與城池都由同一集合推導。讀到正式結尾並點「完成這本」才加入；開啟、定位、自由瀏覽與重讀不新增完成次數。地標多寡不改十四本分母，閱讀完成也不表示實際修證程度。儲存隔離、舊存檔遷移與自由選讀沿用路線規格 r3。

## 8. 城池頁籤保持原規格

本輪精修大地圖美術，不改「城池」頁籤的 SN 35.245 場景。

城喻仍是：城＝色身、六門＝六內處、守門人＝念、城主＝識、雙使＝止觀、廣場＝四大、消息＝涅槃、往返道路＝八正道。

同一書完成可讓大地圖與城池部件同時變化，是同一份閱讀回饋的不同視圖。安那般那在大地圖用竹林與雙溪，城池仍用原定雙使者角色。

完整城喻由 five-aggregates、six-senses、eightfold-path、mindfulness、anapana 完成集合觸發，推薦主線到第 9 本達成。小貓主角與皇冠短鬍子城主沿用既定設計。

## 9. 美術、標籤與圖層

保持精緻童書水彩、柔和光線、花草細節、高角度鳥瞰與明確海岸線。各地景要有辨識差異，避免每本書重新畫成一座山。北方少量雪脊是景觀，不是修證等級。

定欄可有山谷層次，但三本分別以竹林、船塢、靜水庭園呈現。慧欄的四聖諦法輪是直立小型輪形遺跡；十二因緣輪庭是水平地面環院，兩者要一眼可分。

正式互動版至少分開控制：

1. 自然底圖：海面、水道、半島、草地與遠景。
2. 各書地標：湖灣、燈塔、花田、船塢、輪庭、驛站、橋梁裝飾等。
3. 跨書回饋：例如灌溉水流。
4. 完成狀態：薄霧、鎖頭、光暈與活動變化。
5. 翻譯文字、熱區、概念連線與操作介面。

正式美術資產保持無字。概念圖繁體中文標牌僅供此次討論；產品書名、地名、經文、橋梁標牌與操作文字由 HTML/SVG 和翻譯資料呈現，為繁中、簡中、英文、日文保留換行與標籤寬度。

花田與十善業道湖不能烘焙成不可分離的解鎖獎勵；驛站與四聖諦法輪也須分別呈現完成狀態。可依既有技術用透明圖層或分區遮罩，不必重寫大型遊戲引擎。

## 10. 縮放、對齊與簡單操作

背景、地標、熱區、文字錨點與連線使用同一個 1600×900 世界座標，以及相同縮放／平移變換。不要用一個容器裁切背景，再用另一個容器百分比放節點。

16:9 是世界比例，不代表強制裁切所有裝置到滿版。4:3 平板與約 2:1 手機可先完整顯示，再提供放大平移及定位下一本。若採留白，所有標籤與線的變換須計入同一顯示矩形。

島、地景組、橋的同欄 x 是實作依據；文字可避碰、換行或以短引線回到錨點。正精進／正語／正業／正命可用兩行牌面，不改群組中心。

閱讀入口應明顯、可鍵盤操作並有足夠點擊範圍，保留「繼續閱讀」。使用者不必精確操船、駕車、找微小熱區或操作灌溉才可過關。降低動態效果時用靜態完成狀態。

## 11. 實作次序與驗收

建議次序：

1. 先固定 16:9 畫布、五欄座標與概念群組，完成簡圖排版確認。
2. 依此放入兩排群島、大陸、水道與半島；先核對垂直對應，再精修細節。
3. 替換東側五個名稱及八正道舊地標，接續原 book_id 與存檔。
4. 配置一書多景與花田獨立狀態，保留定欄三書的獨立完成記錄。
5. 依核定可玩範圍交付實際畫面，分清已實作、僅美術示意與尚未串接部分。
