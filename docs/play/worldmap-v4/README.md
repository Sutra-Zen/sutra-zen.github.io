# 佛法繪本旅程：大地圖 map-v4／路線 r3

這是既有試作的獨立更新，尚未合併main或公開部署。作者交接版本為 `2026-11-22-map-v4` 與 `2026-11-22-r3`；同名附件原件與雜湊保存於 `handoff/`、`handoff-manifest.json`。最新使用者說明優先，並非附件中的歷史段落另授權發布。

## 試閱方式

從本分支專案根目錄啟動：

```sh
python3 -m http.server 8765 --bind 0.0.0.0
```

在同一台電腦開啟 `http://localhost:8765/play/worldmap-v4/`。這是本機HTTP入口，預定正式網域路徑並未上線。原 `play/visual-v2/` 的畫風比較及舊構圖保留，現有收集書架與原十四本完整閱讀器也保留。必須由HTTP提供ES modules，不要直接雙擊HTML。

新入口為 `play/worldmap-v4/index.html`，原視覺提案與收集頁有連入入口，舊畫風比較仍保留。由此開啟閱讀器時使用選擇性 `collectionReturn=worldmap-v4` 返回這個新地圖；一般收集模式仍回原收集書架，獨立原閱讀器不受影響。外部原經供應者的網路限制不等於來源不存在，也不把固定版本文字核對說成閱讀網站已正常載入。

## 構圖與操作

世界統一1600×900：北側七覺支、近岸五根五力兩排群島，中段多種地景大陸，水道隔開下方八正道公路半島。信、念、勤、定、慧共用固定縱欄；大地圖以薄霧呈現未完成／未揭曉，不放鎖頭。新增圖像無書名或介面字，文字與關係線由HTML／SVG呈現。

左側兩張卷軸沿用五根五力／七覺支原總覽資料；公路西段卷軸只是八正道道路標題。八正道原上方因素排移到半島四組橋；不再留同功能山／島／舊驛站。兩座苦諦湖、法輪遺跡、水平緣起輪庭、鏡影林、木造六念燈塔、花田、竹林雙溪、船塢及靜水庭園各有可辨識地景，非每本都畫成一座山。

閱讀不需要操船、駕馬車、精準點小熱區、灌溉或答題；主要操作仍是開始／繼續閱讀、下一頁與正式末步「完成這本」。完成書籍與場景動畫／略過各自管理。城主是皇冠短鬍子橘貓，旅人不因解鎖而永久穿王裝；止觀雙使採黑白與三花貓，仍維持經典對應與創作外觀的區別。

## 完成集合與場景

大地圖、概念群島、書架及城池都從實際完成ID集合推導，不另維護互相矛盾的「建設完成數」。同一本多個地標只計一次。自由入口不自動完成；自由閱讀正式按完成時只計該本，未滿場景擺放條件的獎勵先供預覽，條件齊備自動安置。

前13本齊備主線才揭曉末本；已開過／已完成的末本不遮回未知。原站與自由閱讀維持可讀。即使末本先完成，仍須全14本才開終章入口，且不要求重讀末本。目前入口呈現已選定的方向與SA262經句，完整終章劇情／演出仍待製作，不宣稱已交付完整結局。實際路線層 `play/route/` 以既有 `sutrazen.play.collection.v1` 的 `completed` 作唯一完成集合，純selector不複製／重排／清空存檔。原 `sutrazen.play.v1` 三本旅程保持獨立；沒有用舊數字關卡猜測完成ID。另設 `sutrazen.play.route-metadata.v1` 只存已知／已開書名與已播放動畫，拒收完成集合或閱讀位置。可辨識的末本第0步書籤也視為已知書名。這是保留既有可辨識ID，不是宣稱已做所有未知歷史格式遷移。詳 `play/route/README.md`；測試仍以實際報告為準。

八正道驛站、公路、橋、溪流及十善業道湖同屬八正道書；四正勤花田獨立，兩本都完成才有額外灌溉。完整SN35.245城喻組合是五陰、六處、八正道、四念處、安那般那，不以序號「9」代替條件。

## 實際新圖與解析度界線

新世界母圖 `play/worldmap-v4/assets/worldmap-master-concept.png` 的實際原生尺寸是 **1672×941**。它是完整互動地圖的共用底圖，不是4K原畫；本輪沒有以放大插值冒充新增細節或原生4K。HTML／SVG的地名、標牌與連線仍可按顯示尺寸清楚繪製，但這不會提高底圖的原生細節。

另提供四張原生1672×941的區域細節概念參照：`detail-northwest.png`、`detail-northeast.png`、`detail-southwest.png`、`detail-southeast.png`。它們是分別生成的區域參照，與母圖有地形／構圖差異，**不是可逐像素拼合的四個象限**。只用於獨立細節查看，不可把四張拼成「同構圖4K大圖」，也不能以其中圖案位置作正式節點錨點。所有互動座標仍依同一1600×900世界／母圖顯示矩形。

新版貓角色城圖 `play/visual-v2/assets/city-cats-concept.png` 原生1536×1024。另有獨立透明 `city-dharma-dock-concept.png` 法輪碼頭圖層，供四聖諦完成後顯示，並不取代城中四大廣場。全部七份圖檔逐位元保留生成輸出，沒有改寫既有書籍圖片；原始尺寸、位元組與SHA-256見 [generated-assets.json](generated-assets.json)。完整同構圖高解析度地圖仍待額外高解析原稿或能維持構圖的正式生成／繪製；尚未交付的原生4K底圖及正式分層動畫素材列為待補，不宣稱已完成。
