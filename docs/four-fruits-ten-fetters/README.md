- `storyboard.json` 是結構化資料，`storyboard.md` 供人工核對。11 幕、74 筆上緣字幕，時間碼為約 2 秒取樣定位。S02 與 S03 交界以 01:26 為準。三果 05:00、05:04 採作者補齊的原句。二果 04:10 採「邠陀利花」，白話亦依經文改為清晨剖開、傍晚枯萎。
- `assets-manifest.json` 列每張圖的幕次、原檔名、尺寸、檔案大小與 SHA-256。正式插畫是 `assets/` 的 11 張 WebP，保留原尺寸及完整畫面。另有替代繫狗圖和經典截圖，放在 `reference/` 供核對。正式 S05 使用柱上「五受陰」、皮帶上「貪愛」的版本。
- 每幕 `topSubtitle` 放上緣、靠左。黑白字依該幕配置，依背景補可讀對比，長句換行。幕名用於目錄。所有幕的 `artOverlay` 均為空，讀取空欄時不產生圖內標題或頁頂摘要；`bakedText` 已在畫中，照圖保留。S02 十結兩側、S05 柱與皮帶、S09 門閂上的「貪／瞋」必須完整可見。保留圖像比例，避免裁切或遮住重要物件。
- 若作者日後新增圖內疊字，使用實際顯示的圖片框作座標基準，逐筆記錄文字、圖片百分比座標、對齊、寬度、避讓區、起訖與直式配置。與上緣字幕、下緣經文及控制按鍵分層。
- `bottomScripture.cues` 記錄換段，包括 S07 03:30、S09 04:52、S10 05:40／05:46。經文索引包含影片節錄或摘要，原典核對後才作直接引文。主體 EA 28.7《增壹阿含經》卷二十〈聲聞品第二十八〉第七經。二果花名的正文用「花」，直接引用開頭列舉的原文保留「華」。影片以四果敘事，四向若需解釋，可放在導讀並標明來源。
