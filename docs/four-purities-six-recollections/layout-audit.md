## 原典與交接差異

四份SuttaCentral官方資料固定版本與逐檔雜湊見`verified-sources.json`。閱讀器使用已核對的漢譯原文／莊春江中譯，不把影片的「錄文或摘要」欄位直接標作逐字經文。

1. S01下緣同列第61經隨信行與隨法行原文，導讀說明「未得果」到「必得果」的先後，避免將「中間不死」讀作肉身不死。
2. S03照分鏡只顯示SN55.1經名；S04／05／06前半／07取同經中譯對應段落。
3. S06在05:51切換五分功德：該原句見SA554，故下緣經名與來源切至SA554。原交接仍保留影片沿標SN55.1的紀錄，未改寫原交接。
4. S08原字幕稱「長者摩訶男」，但SA554的病者是訶梨聚落主長者，開示者是摩訶迦旃延。已詢問作者是否修正；未收到選擇前保留93筆原字幕，在導讀明確說明人物差異。後續若獲確認，用獨立`editorial-corrections.json`記錄，不覆寫原分鏡。
