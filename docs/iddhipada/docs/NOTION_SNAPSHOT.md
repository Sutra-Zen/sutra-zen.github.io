<b>P17｜01:26–01:32｜Q02</b>

<b>P18｜01:32–01:38｜Q02</b>

<b>P19｜01:38–01:43｜Q02</b>

<b>P20｜01:43–01:49｜Q03</b>

<b>P21｜01:49–01:55｜Q03</b>

<b>P22｜01:55–02:01｜Q03</b>

<b>P23｜02:01–02:08｜Q03</b>

<b>P24｜02:08–02:15｜Q02、Q03</b>

這份渴望解脫的心，是「欲」；由此生起的專注，是「欲定」，

<b>P25｜02:15–02:20｜Q02、Q03</b>

而這四種斷惡修善的努力，就是「勤奮之行」。

<b>P26｜02:20–02:25｜Q02、Q03</b>

三者圓滿結合，就成就了「欲定勤行成就如意足」。
