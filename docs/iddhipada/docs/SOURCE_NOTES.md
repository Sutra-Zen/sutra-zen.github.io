### 經文與口白的區分

S01–S07下緣只有經名／經號，並未顯示完整引文。本頁補上對應巴利原經摘錄與本頁中文譯意，供逐幕閱讀；中文譯意不是莊春江譯文，也不是影片下緣逐字稿。各卡附莊春江讀經站原經／中譯對照連結。S08收錄影片下緣中文摘錄；S09收錄古漢譯《雜阿含經》561經及影片口白的差異。原經摘錄不等於全經全文，完整經文由連結閱讀。<br />所有81段口白保留影片敘述，不用摘要取代。引擎、齒輪、划船、公園、心理防禦等屬影片譬喻；不得作為佛陀原話引述。
