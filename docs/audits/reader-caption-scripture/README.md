## 需要作者判斷的白話範圍

這些有具體經文依據，但處理方式涉及故事原意，不能當作程式錯字直接換掉。

- **四不壞淨11頁**：「都已經成為了須陀洹」容易混淆向、果；所引61經明說隨信行、隨法行「**未得須陀洹果**」，後面才另說三結盡的果位。**12頁**完整句「中間永不死去，必定能走向彼岸……涅槃」也宜釐清：原經是「中間不死，必得須陀洹果」，宜說清楚這裡的期限與結果，避免讀成肉身不死。
- **八正道64–66頁**：把世俗正方便說成追逐快樂而更累，容易把「世俗正方便」誤等同貪欲；785經仍說它「轉向善趣」。75–86頁記得／看清的故事，也不宜單憑看清情緒就等同出世間無漏正念。
- **四向四果28頁**：初果斬斷前幕代表貪愛的整條皮帶，容易使人以為初果已斷一切貪愛；原經在此只說三結。46–50頁借阿羅漢德相段的「斷關」說明三果，宜交代是共同斷五下分結性質的借喻。
- **四念處91、107–109頁**：七覺支所選段沒有直接說初禪至四禪；牧牛善念譬喻也不能單憑這一段便等同四念處圓滿或已證涅槃。其餘四大／六界、所附節錄與故事結句的範圍差距，見分組報告。
- **五陰4–6頁、十二因緣7–12、60–64頁**：宿命智回憶前世不宜寫成預知未來生命；緣起的「有」不宜等同不可逆的命運；「不思量／不妄想」也需依原經上下文理解，不能只憑停止念頭便等同終結生死。這些是既有白話的語義界線，詳首四本報告，不當成翻頁器放錯卡。

全量的原句、頁碼、檔案行號、原典證據及建議分列於下方四份報告；這裡只突出容易讓讀者誤會的部分。敘事中的小貓、船、花園、鎖鏈、魔鏡等創作，不因經文未逐字提及就判為錯誤。

## 實際驗證與可重現方式

- [正式站檔案比對](live-files.json)：正常CA驗證的HTTPS抓取46份HTML／書稿資料／原閱讀JS／bridge，逐位元符合本次稽核版本。不是只相信交接文件。
- [官方原典取得紀錄](source-receipts.json)：固定版本URL／SHA及可用性。SuttaCentral官方GitHub的漢譯、具名中譯、巴利資料及CBETA原檔供校核；部分Buddhaspace／莊春江站直連受本環境CONNECT403阻擋，已採官方資料核對，未將封鎖解讀成該經不存在。

```sh

python3 -B scripts/audit-reader-game-content.py
python3 -B scripts/audit-reader-live-content.py
```
