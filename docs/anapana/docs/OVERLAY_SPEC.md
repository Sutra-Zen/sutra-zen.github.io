### 三種文字層必須分開

1. 原圖內嵌文字：已在像素內，只列出清單，不重畫、不重複疊加。
2. 教學疊字：只加各幕表格所列文字；固定在原圖相對座標內，不能統一丟到網頁最上方。
3. 口白與經文：用圖外的可閱讀文字區與經文卡呈現。口白有段落編號，每段連到指定Q編號；不能把一整幕不同經文縮成片尾一條來源，也不把長經文壓在插畫下緣。影片播放式字幕若另做，屬獨立字幕層，不可拿來代替圖內教學字。

### 疊字實作共同規格

座標是原圖全幅（包含奶油色外框）左上角為(0,0)，單位為百分比。x、y指定文字框左上角；width指定框寬。使用position:absolute、left:x%、top:y%、width:w%，不要再套translate(-50%,-50%)。字級單位cqw，以圖框寬為基準；全局設container-type:inline-size。字體採繁體中文字型，粗體700，line-height:1.15，text-align:center，pointer-events:none。

圖框須以原始寬高比呈現，img width:100%;height:auto;display:block；疊字與圖共用同一個position:relative容器。不可用object-fit:cover裁切後仍套舊座標，也不可將經文卡或上下控制列算入圖框高度。原片座標為目測重建值，以下是可執行初值，網頁完成後須看原圖實際避讓校準。
