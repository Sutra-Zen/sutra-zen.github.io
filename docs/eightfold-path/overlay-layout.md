## 正志先行試排

左側的毒花、DANGER/TOXIC整塊木牌沒有足夠空間；改在圖內上方中央偏右（44.5%、2.5%、寬41%）兩行靠左。保留眼鼻口、羅盤、毒花與槍身；少量貓耳／額頂毛色會位於字後。這是試排、等待作者看圖確認，不是原影片位置還原。`protectedRegions` 是本次檢查用的近似避讓矩形，不冒充插畫自動物件辨識。

為避免上緣旁白壓住圖內文字，橫式保留上下文字帶，把完整圖片等比例放在中間；以同幕最長旁白固定預留高度。直式同樣避免上緣字數變動造成圖片跳動。每個疊字都在圖片frame內定位，方向切換不靠整個視窗計算。

## 四格文字與焦點

- 惡行：左上偷盜（字幕1–2）、右上殺生（3）、左下妄語（4）、右下心不定（5–10），文字位於當格下緣並避開側邊翻頁鍵。第3筆字幕同時提砍樹與鳥蛋，前兩頁已先展示砍樹，此頁聚焦鳥蛋，沒有拆改原句。
- 依作者校訂，右下「心不定」只標示故事中的心理狀態，不列為十惡業。
- 正語：左上道歉亮格，下緣顯示正語；完整「不妄語，不兩舌，不惡口，不綺語」置相鄰右上暗格，以兩行呈現而不切斷單一詞語，避讓道歉的角色。未增加其他標籤。
- 善行四格：右上拾木／不偷盜、左下護蟲／不殺生、右下安睡；只在前段暗格放當頁十善對照，移除正業標題，安睡段不加疊字。
