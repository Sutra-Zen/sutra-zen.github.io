## 重現與本機預覽

```sh
python3 -B scripts/check-reader-dark-heart.py
```

需要環境既有的Playwright、lxml與`/usr/bin/chromium`。腳本使用獨立本機HTTP連接埠與隔離存檔；`--resume`只續跑已完成配置以外的組別。本次心經完成組保留，候選欄位讀取修正後續跑口白組；最後report沒有未解決失敗。未重讀29步主線或整站1192步。

人工預覽：在專案根目錄執行`python3 -m http.server 8000`，開啟`http://127.0.0.1:8000/four-truths/book/`，用目錄／下一頁進入心經；遊戲複習應經合法已讀書架入口進入。
