## 重現

完整repository ZIP解壓後於根目錄執行`python3 -m http.server 8765`，開啟`http://127.0.0.1:8765/right-effort/`。

```sh
python scripts/build-right-effort.py --check
python scripts/check-right-effort.py --screenshots --verify-sources
```

需要Python、Playwright、Pillow、lxml、Chromium。360×800、800×360、768×1024、1024×768、1440×900，共405個逐頁狀態通過；完整口白、指定經文切換、原圖比例、百分比座標／字級／遮罩、文字在圖下及圖片不被文字／按鍵覆蓋、無水平溢出、目錄、翻頁、快速翻頁、經文視窗／捲動、來源返回、旋轉／重載保留頁碼、圖片放大、末頁重讀、新書架／心智圖及舊八本入口皆已測試。原八本、共用檔案及Pages設定逐位元組保持不變。6份官方原典／中譯原檔已重新下載核對SHA-256。
