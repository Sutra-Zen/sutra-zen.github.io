## 建議的組織

- 綠色上層：以《雜阿含經》801、803經及《中部》118經的準備／入出息念為經典導讀主線。箭頭是本頁的導讀敘述順序，不是另訂必須逐關達成的修證程序。
- 暖色下層：調身、調心兩張平行的「需要時參照」補充卡。調身虛線連安坐；數隨止虛線連入出息中的攝心。兩卡之間沒有相接的必經箭頭，也沒有把它們插成準備與十六勝行之間的關卡。
- 「觀」在十六勝行已有身、受、心、法的觀察；金剛寺本的「觀」另有五陰／生滅的內容，可以對讀，保留各自文獻架構。沒有把安般六事與十六勝行等同或逐項硬配，也沒有替阿含額外增加「完成數隨止，再完成一個觀，才能修十六勝行」的前提。
- 《修次中編／下編》屬蓮花戒的論師材料；《安般守意經》金剛寺本則依本頁既有古譯文獻名稱標示。因此共同層級稱「實修補充」，沒有把金剛寺本的所有內容簡化為某位論師的自創法。
- 原表四組與完整16項直接整合至右上十六勝行卡片，以四列分組顯示，取代上一稿的小格摘要。心悅／心定與插畫心喜／心攝的原備註移入同一張卡片。移除草稿下方的獨立表格，各項只出現一次；16項、4組名稱、順序與備註逐一比對原表文字相同。

## 依據與核對界線

本輪先讀專案AGENTS、PROJECT、HANDOFF與實際專頁，再讀交接SOURCE_NOTES、STORYBOARD及verified-sources，核對本庫既存canonical與附件PDF；所有來源檔SHA-256均與verified-sources一致。沒有依靠未讀Notion或影片推定來源。

1. 《雜阿含經》801經：淨戒、少欲少事少務、飲食知量、初後夜不著睡眠及空閑林中。
2. 《雜阿含經》803經：端身正坐、繫念面前、遠離五蓋、念於內外息，以及後續身受心法相關內容。經文本已含實作指導，補充用來展開細節；沒有採用「佛陀沒有教實作」的斷語。
3. 《中部》118經：四組入出息念與身、受、心、法四念住的對讀；不新增新經號或改寫各譯本用語。
4. 《雜阿含經》464經：「修習於止，終成於觀，修習觀已，亦成於止。」只作止觀互相成就的依據，不據此編造唯一固定時間順序。
5. 蓮花戒《修次中編／下編》：使用本頁已核對的《菩提道次第廣論》卷十四引述（B10n0067_p0715a13；實際引文段落0718a24–0718b03），不是聲稱新做了中／下編各自原本校勘。
6. 金剛寺本數／隨／止：使用現有來源與作者補訂。「觀、還、淨」延伸依鄧翠盈（釋妙博）2008年論文：印刷頁122／PDF130有六事的止觀分組，印刷頁126–127／PDF134–135轉引「觀為何等…觀新新生滅相…」，並討論五陰、身受心法。已實際讀取相應PDF頁文字，不把論文研究說明冒充本書已採的原片經文，也沒有改原稿／經文卡。

來源入口沿用正式專頁的原經區，以及本庫既有論文PDF第134頁。這是閱讀架構／教學關聯示意，供作者確認後才考慮整合正式專頁；若未來擴充觀還淨的完整經文卡，應另外核對引文與版本。
