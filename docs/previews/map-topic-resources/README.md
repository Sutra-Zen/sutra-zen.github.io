# 全心智圖三入口卡片（2026-11-21）

作者確認淡紫／淡藍／淡珊瑚試排後，授權套用全部節點並發布。32個可點節點統一為專頁說明、翻頁繪本、繪本影片；topics.json列出逐節點對應，30個主題／子項直接連至既有14本導讀、閱讀器及原YouTube網址。道路及相關內容總覽的前兩卡以「從書架選擇」明示目的，影片連既有影片區；頁內跳轉關閉彈窗。

只調整彈窗的資源入口與共用map-topic-resources.css。原精簡說明、標題、十四個影片iframe、書架連結及所有繪本內容／插圖／經文不改，原有影片URL及另開分頁行為保留。原試排PR #51將由本次完整實作取代，不另行合併。

驗證程式scripts/check-map-topic-resources.py逐節點比對舊版說明、檢查本機路徑及連結；以360×800、390×844、768×1024、1024×768、1280×900測試160個彈窗狀態、卡片配色／可捲動與點擊／關閉／無水平溢出，並從三張卡片實際開啟14本導讀與繪本，確認圖載入、上一頁／下一頁頁碼變化與返回地圖，共70條往返路徑，另測總覽頁內跳轉與影片另開分頁。

validation.json為本機結果；PNG為實際瀏覽器截圖。正式發布後，以390×844及1024×768重驗正式站的64個彈窗與28條往返動線；Pages同SHA、HTTPS檔案與ZIP核對證據記入本次PR。正式站瀏覽器測試使用TLS驗證的urllib讀取原站回應以處理管理瀏覽器代理憑證；Tailwind及Lucide使用既存下載副本，非外站CDN驗收。影片只檢查原網址與新分頁，未測播放；實體Safari亦未測。
