# 全十四本返回地圖與閱讀格式統一

2026-11-20，基準main a3dc88dcd39c353c1587f6de675883012f9b79fa。

## 修正與範圍

前九本只有閱讀原經，後五本已有返回地圖，已補齊十四本的「閱讀原經／回修道地圖」。前三本的「展開經文」統一為「本頁經文」。共用reader-controls.css保留觸控與重讀，補入來源區按鈕留白，依實際置中的scene寬度計算，而非沿用部分書不適用的gutter變數，避免新增按鈕擋住經文。

原前四本的橫式字幕／經文仍疊在完整圖片上，直式另有負邊距壓圖及平板寬度觸發絕對定位。新增reader-layout.js只讓這四本的插畫頁採上下圖外欄、完整原圖等比置中，並隨圖片載入、翻頁、字型及旋轉量測。八正道的無疊字頁同樣修正；已有overlay-scene的版型保留。心經直書、純文字頁、結語、圖內原字與百分比疊字不改寫、不裁切。各書特有圖幅／字幕色彩保留；後七本既有圖片放大功能不移除，本輪沒有另行把新功能移植成早期七本的另一套介面。audit.json保留逐本前後盤點。

全部原稿、經文、內嵌script/style/圖片及各書資料／JS／CSS對基準main逐檔相同；變更只在閱讀器HTML操作、共用UI及格式適配。七覺支既有離線ZIP同步共用CSS，29檔CRC／manifest全雜湊通過；離線回到離線目錄，不連往不存在的地圖。

## 實測

`python3 scripts/check-reader-navigation.py`：360×800、800×360、768×1024、1024×768、1440×900。原前四本橫式每一頁逐頁檢查，其餘取首、次、中、倒數與末頁，共1115狀態／988圖文幾何狀態；70次原經→繪本→直接回地圖、70次旋轉保留進度、58個實際有引文的經文視窗，末頁重讀及快速前後點按均通過，無JS／本機HTTP錯誤與水平溢出。實際矩形確認字幕在圖上、經文在圖下、左下兩連結不壓經文。validation.json與十張iPad橫直截圖保存實測。

本機根目錄HTTP測試；首頁CDN以環境已有Tailwind及下載Lucide副本提供，不宣稱外站CDN或實體Safari已驗收。正式發布後可執行`python3 scripts/check-reader-navigation.py --live`：環境瀏覽器缺少代理憑證信任，因此以保留TLS驗證的urllib讀取新站原始回應後傳送給瀏覽器，仍在正式站URL執行。各資源須HTTP200且與本次合併版本逐位元組相同；每次請求附release SHA避免舊快取。正式雙尺寸／28入口結果、Pages同SHA／workflow及完整備份紀錄於本次PR；不能把此傳輸驗證說成實體iPad測試。
