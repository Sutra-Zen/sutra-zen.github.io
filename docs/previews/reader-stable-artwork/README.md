## 可重現方式

在專案根目錄執行：

```sh
python3 -B scripts/check-reader-stable-artwork.py
```

需要目前環境的Python Playwright、lxml及`/usr/bin/chromium`。腳本使用獨立本機HTTP連接埠與隔離瀏覽器存檔，更新本目錄的驗證資料。這次為減少大型內嵌圖檔重載，42組原生翻頁後重用同一閱讀器旋轉／調整尺寸，並將公開及遊戲矩陣分工執行後依視窗／書本／模式去重合併。

人工預覽可執行 `python3 -m http.server 8000`，開啟 `http://127.0.0.1:8000/four-truths/book/`。遊戲複習應經遊戲書架的合法已讀入口進入；直接設定URL不會給予已讀資格。
